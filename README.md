# el_edil

Консольный скрипт на Node.js для замера скорости скачивания. Скрипт:

1. принимает адрес, например тяжёлую картинку;
2. делает к нему **10 запросов по очереди** и каждый раз ждёт, пока ответ скачается целиком;
3. считает **среднее время запроса** и **общий объём** скачанных данных;
4. печатает **скорость скачивания**.

Внешних зависимостей нет, используются только `fetch` и `node:test`, которые есть в самом Node.js.

## Требования

- Node.js **18+**

## Запуск

```bash
git clone <repo-url>
cd el_edil

node src/cli.js <url>
# или
npm start -- <url>
```

Пример:

```bash
node src/cli.js https://proof.ovh.net/files/10Mb.dat
```

## Единицы измерения

| Величина         | Единица                                             |
|------------------|-----------------------------------------------------|
| Время запроса    | миллисекунды (**ms**)                               |
| Объём            | мегабайты, **MB** (1 MB = 1 000 000 байт)           |
| Скорость (основная) | мегабиты в секунду, **Mbit/s** (1 Mbit = 1 000 000 бит) |
| Скорость (доп.)  | мегабайты в секунду, **MB/s**                       |

Основной единицей выбран **Mbit/s**: в ней указывают скорость интернета провайдеры и сервисы вроде Speedtest, так что результат легко сравнить. MB/s выводится рядом, потому что в этих единицах проще прикидывать, сколько будут скачиваться файлы.

Используются десятичные приставки (СИ), а не двоичные (MiB).

## Как считается

- **Время запроса**: от отправки запроса до получения последнего байта тела ответа (`performance.now()`). Сюда входят DNS, TCP/TLS (если соединение не переиспользовано), ожидание первого байта и само скачивание.
- **Среднее время** = сумма времени всех запросов / 10.
- **Общий объём** = сумма байт тела всех 10 ответов. Тело читается потоком, поэтому большой файл не нужно целиком держать в памяти.
- **Скорость** = общий объём / суммарное время всех запросов.

Детали:

- Запросы идут строго последовательно: следующий начинается только после того, как предыдущий скачан полностью.
- Отправляется `Accept-Encoding: identity`, чтобы сервер не сжимал ответ и посчитанные байты совпадали с реально переданными. Также отправляются `Cache-Control: no-cache` и `User-Agent`, без которого некоторые серверы отклоняют запросы.
- Если код ответа не 2xx, если случилась сетевая ошибка или запрос висит дольше 60 секунд, скрипт завершается с кодом `1` и пишет причину.
- Объём считается только по телу ответа, без HTTP-заголовков.

## Тесты

```bash
npm test
```

Тесты поднимают локальный HTTP-сервер и проверяют четыре вещи: что тело скачивается полностью и байты считаются правильно, что запросы не идут параллельно, что ответ с ошибкой обрабатывается, и что единицы пересчитываются верно.
